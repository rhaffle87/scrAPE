# scrAPE Output Directory

This directory stores crawl results, media assets, state caches, and execution reports generated by scrAPE runs.

## Directory Structure

```text
output/
├── cache/
│   ├── state_cache.db       # Persistent SQLite URL deduplication cache
│   └── dedup_index.db       # Hierarchical deduplication and perceptual hash index
├── {keyword_or_subject}/
│   └── runs/
│       └── {timestamp}/
│           ├── manifest.json            # Complete scrape execution result
│           ├── run_summary.json         # Structured post-run observability report
│           ├── domain_report.json       # Per-domain crawl metrics
│           ├── results.db               # Exported SQLite relational database
│           ├── crawl_dataset.parquet    # Columnar dataset table (if --export-parquet)
│           ├── rag_payload.jsonl        # Vector embedding chunks (if --export-rag)
│           └── media/                   # Downloaded images and videos
│               ├── images/
│               └── videos/
```

## Data Retention & Maintenance

To purge old scrape runs according to data retention policies:
```bash
python src/cli/cleanup.py --days 7
```
