MODULE [01] // REQUIREMENTS & SCOPE

Core System Scope

High-speed, multi-engine stealth web scraping engine designed for autonomous media extraction and dataset generation.

1.1 System Architecture & Objectives

scrAPE is an enterprise-grade, multi-tier web extraction engine engineered to crawl complex Web2 and Web3 platforms, bypass WAF protections (Cloudflare, Incapsula, Datadome), and generate high-resolution image/video datasets for AI training models (Kohya_ss LoRA, Stable Diffusion).

[!] CORE OPERATIONAL GUARANTEE
The system executes via an 8-tier WAF fallback pipeline, ensuring request escalation from lightweight direct HTTP requests up to headful stealth browser automation when Cloudflare challenge loops are detected.
Component Implementation Layer Primary Function
CLI Engine src/cli/main.py Primary execution interface accepting flags, seeds, and extraction budgets.
BFS Crawler Engine src/core/engine.py Asynchronous Breadth-First-Search link traversal, page scoring, and worker thread pool.
Stealth Pipeline src/network/stealth_pipeline.py Dynamic 8-tier WAF escalation pipeline with circuit breaker isolation.
Media Downloader src/storage/file_downloader.py Concurrent media stream downloader with MIME/size validation and rejected item retention.
WebUI Dashboard frontend/app.py Decoupled FastAPI + HTMX dashboard with real-time SSE log streaming and visual network tree.

Scope & Non-Goals

Strict architectural boundaries and coding constraints.

1.3 Architectural Rules & Boundary Enforcement

[!] MANDATORY RULE: NO HARDCODED DOMAIN RULES IN SOURCE
Never hardcode domain-specific URL normalization rules or subject names directly in Python source files under src/. All URL canonicalization rules MUST reside in data/url_normalisation_rules.json and domain configurations in data/domain_config.json.

Complete CLI Flag Matrix

Complete, exhaustive reference of all main.py command-line options.

2.4 CLI Parameter Reference

Flag Type Default Description
--keyword string None Target keyword or subject name to search and extract.
--seed-file string None Path to .txt seed manifest file containing URLs and annotations.
--download-media flag False Download discovered images and videos into output/<subject>/.
--save-rejected string None Comma-separated rejection reasons to save to disk (e.g. low_subject_relevance,preview_or_thumbnail).
--max-results int 50 Maximum media items per type to download. Use 0 for unlimited.
--workers int 6 Number of page parsing worker threads operating concurrently.
--dl-workers int 16 Number of media stream downloader worker threads.
--page-limit int 100 Maximum pages to fetch during the BFS crawl loop.
--crawl-depth int 2 Maximum recursion depth for discovered link traversal.
--strict-domain flag False Restrict crawl strictly to domains declared in the seed file.
--use-state-cache flag False Persist processed URLs in SQLite DB (state_cache.db) across runs.
--clear-cache flag False Clear state cache database before starting the crawl.
--ignore-robots flag False Bypass robots.txt restrictions.
--capsolver-key string None API key for automated CapSolver WAF challenge resolution.

Quality Scoring & Rejection

Hard rejection rules, soft penalties, and rejected item disk retention.

3.4 Quality Scoring Heuristics

Every candidate media URL is evaluated by `src/core/filters.py` before downloading:

Rejection Reason Token Trigger Criteria Retention Path
low_subject_relevance Subject name absent in URL path, alt-text, and surrounding context text. output/<subject>/rejected/low_subject_relevance/
preview_or_thumbnail URL matches thumbnail patterns (e.g. 256px, pic256.jpg, /thumbs/). output/<subject>/rejected/preview_or_thumbnail/
utility_asset File is a UI logo, icon, avatar, sprite, or tracking pixel. Discarded unless explicitly saved.
